# PLUITS Social Reaction Characters

**Purpose:** curated animated human/character expressions for comments and other approved social interaction surfaces.

This library is intentionally separate from PLUITS Fluvara. Fluvara is for profile-cover identity; Social Reaction Characters are for expressive social interactions.

## Exploratory expression families

- Laughter
- Joy
- Surprise
- Affection
- Sadness
- Confusion
- Encouragement

These are concept directions, not a finalized sticker catalogue.

## Asset rules

- Use original commissioned/created assets or third-party assets with explicit licenses for the intended in-product distribution.
- Record creator, copyright owner, source, license, restrictions, and attribution.
- Do not assume that a stock animation license permits redistribution inside a downloadable or reusable asset library.
- Each reaction should have an accessible name and a static or reduced-motion fallback.
- Keep asset IDs, previews, source files, and delivery variants traceable.
- Do not mix member uploads with the official curated collection.
