# PLUITS Fluvara — Profile Cover Assets

**Purpose:** curated still-image, video, and original fluid-motion assets for member profile covers.

**User-facing path:** Pengaturan Profil → Edit Sampul → Pustaka Sampul → Fluvara.

## Asset rules

- Add only original PLUITS work or third-party assets with documented licenses covering the intended distribution and member use.
- Do not store member-uploaded cover media here.
- Do not describe a licensed asset as copyright-owned by PLUITS.
- Keep source files, approved delivery variants, previews, and provenance records traceable by asset ID.
- Provide a reduced-motion/static alternative where motion is used.
- Keep the collection preview-first and do not publish unfinished placeholder artwork as real content.
