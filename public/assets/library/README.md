# PLUITS Curated Asset Libraries

This directory is reserved for curated, approved static visual assets owned by PLUITS or distributed under documented licenses.

It is not a storage location for member uploads, private files, or unreviewed third-party downloads.

## Asset families

- `profile-covers/fluvara/` — PLUITS Fluvara profile-cover collection.
- `social-reactions/characters/` — animated human/character reactions for comments and approved social interactions.

## Governance

Before adding an asset:
1. Assign a stable asset ID and category.
2. Record creator, copyright owner, source, license, permitted uses, restrictions, and attribution requirements.
3. Confirm the source file and approved delivery variant.
4. Provide a preview and accessibility description.
5. Review performance, mobile suitability, and reduced-motion fallback.
6. Update the canonical specification and asset catalogue.

See `PLUITS-MASTER-MODEL-APP/02-PRODUCT-DESIGN/01-SOCIAL-MEDIA/PLUITS-VISUAL-ASSET-LIBRARIES-001.md`.

No production media assets are included yet. The folders contain governance notes only.
