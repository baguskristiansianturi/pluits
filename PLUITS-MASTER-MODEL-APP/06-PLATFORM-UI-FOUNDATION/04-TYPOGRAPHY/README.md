# 04 — Typography

Owns the approved type families and the full typographic scale.

## Register scope

- Font family and permitted fallback stack.
- Approved font files, weights, and styles.
- Type scale for display, headings, body, labels, and captions.
- Line heights, letter spacing, and text transformations.
- Language and character coverage.
- Font loading, performance, and fallback behavior.

## Rules

- Pages use the approved type tokens rather than independently selecting fonts or sizes.
- Do not fetch or embed a new font without product-owner approval and a licensing check.
- Define hierarchy semantically; do not use size alone to communicate meaning.
- Verify readability, wrapping, truncation, and scaling at supported viewports.

## Not yet approved

No new font family or final type scale is selected by this setup. Audit the current runtime font assets and present recommendations for review.
