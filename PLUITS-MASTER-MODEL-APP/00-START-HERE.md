# PLUITS Master Model App — Start Here

Gunakan folder ini sebagai pusat dokumentasi rancangan. Source code aplikasi yang sedang berjalan tetap berada di `src/`, `public/`, `styles/`, `supabase/`, dan konfigurasi/build repository.

## Urutan membaca
1. Master Foundation.
2. Model ekosistem yang sedang dibahas.
3. **Platform UI Foundation** untuk standar visual, ukuran, aset, komponen, responsivitas, layout/interaction patterns, dan SOP yang berlaku untuk seluruh halaman.
4. Product Design untuk kebutuhan pengguna, pengalaman, struktur, dan komposisi halaman.
5. Application Modularization untuk kepemilikan source, batas teknis, arsitektur, integrasi, testing, deployment, dan rollback.
6. Platform Wrapper untuk pengalaman shell dan perjalanan lintas aplikasi.

## Aturan pekerjaan UI
Sebelum membuat atau mengubah halaman, baca `06-PLATFORM-UI-FOUNDATION/00-FOUNDATION-GOVERNANCE.md` dan SOP terkait. Gunakan hanya material yang berstatus Approved. Jika kebutuhan belum tersedia di library, laporkan kepada pemilik produk dan jangan mengambil atau membuat pengganti secara sepihak.

## Alur sharing
