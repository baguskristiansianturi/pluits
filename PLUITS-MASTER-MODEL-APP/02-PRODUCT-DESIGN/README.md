# Product Design

Area untuk product brief, persona, information architecture, sitemap, user journey, flow, page inventory, kebutuhan UI/UX, wireframe, visual references, dan acceptance criteria setiap aplikasi.

## Batas tanggung jawab
- Product Design menentukan **apa yang dibutuhkan pengguna, halaman apa yang dibuat, susunan/komposisi halaman, dan perilaku spesifik pengalaman produk**.
- Platform-wide visual rules, design tokens, responsive measurements, approved brand assets, typography, icon/component libraries, shared layout/interaction patterns, serta UI creation SOP berada di `../06-PLATFORM-UI-FOUNDATION/`.
- Setiap folder aplikasi di Product Design wajib merujuk dan menggunakan Platform UI Foundation. Jangan menyalin atau membuat standar global tandingan di folder ekosistem.

Setiap aplikasi memiliki folder desain sendiri. Desain halaman boleh berbeda sesuai kebutuhan, tetapi tetap memakai fondasi antarmuka bersama PLUITS.
