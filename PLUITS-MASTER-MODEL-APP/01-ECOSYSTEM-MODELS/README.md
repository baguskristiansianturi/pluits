# Ecosystem Models

Urutan enam model utama PLUITS:

1. Social Media
2. [Marketplace](02-MARKETPLACE/README.md)
3. Tickets & Accommodation
4. Geo Directory
5. Logistics, Courier & Transportation
6. Digital Wallet

## Struktur di dalam model

Marketplace menampung indeks vertikal merchant yang terhubung dengannya, saat ini:
- Store
- Restaurant & Café

Store dan Restaurant & Café adalah modul operasional merchant di bawah cakupan Marketplace, bukan model ekosistem sejajar. Model lain boleh tetap berupa folder dasar sampai sesi perancangan dan requirement-nya dimulai.
