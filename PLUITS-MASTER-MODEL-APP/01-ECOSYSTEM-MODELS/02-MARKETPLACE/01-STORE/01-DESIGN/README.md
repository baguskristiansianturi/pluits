# Store — Design

Ruang rancangan bisnis dan pengalaman pengguna PLUITS Store.

## Cakupan
- Model multi-seller dan kelayakan toko fisik
- Verifikasi dan persetujuan merchant oleh PLUITS
- Seller Center, profil toko, katalog dan discovery
- Produk, kategori, atribut, varian/SKU, media dan persediaan
- Halaman, navigasi, alur pelanggan dan alur operasional merchant
