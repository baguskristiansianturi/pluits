# Reels — Product & UX Design

## Tujuan
Konten video pendek dengan pengalaman konsumsi vertikal, pemutaran, kontrol media, discovery, interaksi, dan aturan distribusi video.

## Isi yang wajib didefinisikan
- Persona/aktor dan kebutuhan pengguna.
- Information architecture, sitemap, routes, dan page inventory.
- Creator/user journey serta skenario utama, alternatif, empty, error, loading, offline, dan permission states.
- Struktur halaman, hierarki informasi, interaksi, gesture, keyboard, responsive behavior, dan accessibility.
- Content model, audience/privacy states, moderation/reporting, notification, dan discovery entry points.
- Acceptance criteria per halaman dan interaksi.

## Kepemilikan visual
Reels memiliki lifecycle media, playback, preloading, mute/audio, caption, progress, gesture, discovery, moderation, dan performance budget sendiri. Jangan menaruh aturan playback ke CSS atau controller Blog, Stories, maupun Live.

Visual khusus modul ditentukan di sini. Logo, ikon, typography, warna, spacing, ukuran, breakpoint, dan komponen fondasional tetap mengacu ke Platform UI Foundation. Catat kebutuhan komponen baru sebelum membuat duplikasi.

## Larangan
- Jangan menganggap prototype sebagai desain final atau fitur produksi.
- Jangan menyalin layout/interaction model dari modul lain tanpa validasi kebutuhan.
- Jangan menetapkan token global baru di folder modul.
