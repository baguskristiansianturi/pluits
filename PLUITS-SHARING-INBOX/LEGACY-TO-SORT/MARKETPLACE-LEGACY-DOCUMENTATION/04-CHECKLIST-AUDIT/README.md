# Marketplace — Checklist & Audit

Gunakan folder ini untuk audit UX/UI, fungsional, integrasi merchant, keamanan, performa, aksesibilitas, dan kesiapan rilis Marketplace.

## Checklist minimum

- [ ] Homepage Marketplace terpisah jelas dari homepage global PLUITS.
- [ ] Discovery dan kategori merchant bekerja sesuai kontrak.
- [ ] Store dan Restaurant & Café tampil sebagai vertikal berbeda.
- [ ] Detail merchant mengambil data dari sumber resmi modul terkait.
- [ ] Alur transaksi tidak mengambil alih aturan operasional vertikal.
- [ ] Empty, loading, error, dan unavailable states tersedia.
- [ ] Mobile layout diuji pada viewport ponsel.
- [ ] Tidak ada regresi pada homepage, Inbox, Profile, Community, navigasi, CSS global, atau modul lain.
- [ ] Backend/RLS dan migrasi diperiksa sebelum rilis.
- [ ] Hasil deploy dan smoke test dicatat.
