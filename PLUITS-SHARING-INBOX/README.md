# PLUITS SHARING INBOX

Folder penampungan tunggal untuk hasil setiap sesi sharing, diskusi, ide, koreksi, dan kebutuhan baru sebelum disortir.

## Aturan
1. Setiap sesi dibuat sebagai satu file di `SESSIONS/`, gunakan template `SESSION-TEMPLATE.md`.
2. Catat apa yang disampaikan, masalah yang ditemukan, usulan, keputusan eksplisit, pertanyaan terbuka, dan tindak lanjut.
3. Jangan menganggap isi sesi sebagai keputusan final hanya karena sudah ditulis.
4. Setelah sesi ditinjau, pecah hasilnya menjadi perubahan terarah di folder Ecosystem Models, Product Design, atau Application Modularization.
5. Catat lokasi hasil sortir dan statusnya di `SESSION-INDEX.md`.
6. Materi lama yang belum diklasifikasikan berada di `LEGACY-TO-SORT/`; ini bukan sumber kebenaran aktif.

## Status
RAW → UNDER-REVIEW → SORTED → ACCEPTED / REJECTED / DEFERRED.
