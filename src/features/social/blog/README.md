# Social Blog

Owner: Social Media domain. Route: `/blog/`.

- `blog-page.js`: independent Blog page composition, category filtering and local search.
- `blog-page.css`: Blog-owned responsive stylesheet scoped to `.sm-blog-page`.

Current page content is static frontend preview data. Article detail routes, editor, draft/publish lifecycle, persistence, comments, author records and backend integration are not yet active. Do not represent preview fixtures as published user content.
