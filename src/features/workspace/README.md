# Internal Development Workspace

Owner: features/workspace  
Status: temporary authenticated workbench; not the final Global Home or account dashboard.

The workspace appears after a valid Supabase session is available. It presents the agreed build sequence, the Sharing Inbox to Master Model process, and links to the canonical repository documentation.

The screen is intentionally informational. It does not claim to store chat sessions, project tasks, or approvals in the database. Those capabilities require a separate product and data-model audit.
